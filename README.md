# CelGrade LM — Downloads

Instaladores e atualizações para Windows x64.

Acesse [Releases](https://github.com/LuuizV/CelGrade-LM-Releases/releases) e baixe o arquivo `CelGrade-LM-Setup-<versão>.exe` da versão desejada. Os arquivos `.blockmap` e `latest.yml` são usados pelo atualizador.

A partir da versão 0.4, o aplicativo consulta novas versões ao abrir, pede confirmação antes de baixar e só instala quando você escolhe reiniciar. Sem internet, continua funcionando.

Antes de migrar da versão 0.3 portátil, exporte seu backup JSON e feche o aplicativo antigo. Instale a nova versão e confira seus dados; se necessário, restaure o backup em Dados e backup.

O programa mantém os dados no computador. Antes de instalar uma atualização, cria um backup JSON na subpasta `backups-atualizacao` da pasta de dados.

Este repositório não recebe cadastros, grades ou informações de formandos. Não envie backups pessoais nas issues.

O instalador inicial não possui assinatura Authenticode. A instalação e a atualização entre duas versões devem ser validadas em Windows antes do uso definitivo. O repositório de desenvolvimento é privado; isso não impede a inspeção do JavaScript distribuído no aplicativo Electron.
